# 🏨 Hotel Booking Data Analysis & Interactive Dashboard

## Project Overview

This project focuses on analysing hotel booking data to uncover meaningful business insights, understand customer booking behaviour, identify cancellation patterns, and explore revenue trends.

Using Python and data analytics libraries, I performed data cleaning, exploratory data analysis (EDA), statistical analysis, and data visualization. The project also includes a Streamlit application designed to present key findings through an interactive dashboard.

The objective is to transform raw booking data into actionable insights that can support data-driven decision-making in the hospitality industry.

## 🎯 Project Objectives

- Understand hotel booking patterns and seasonal trends.
- Analyse customer behaviour and market segment distribution.
- Investigate booking cancellations and their potential business implications.
- Explore guest demographics and country-wise booking distribution.
- Evaluate room reservation and allocation patterns.
- Analyse Average Daily Rate (ADR) and revenue-related trends.
- Present analytical findings through clear and interactive visualizations.

## 📊 Key Areas of Analysis

**1. Data Cleaning & Preprocessing**
- Handling missing values and duplicate records.
- Identifying inconsistent and invalid data.
- Preparing data for further analysis.

**2. Exploratory Data Analysis (EDA)**
- Analysing booking distributions and customer patterns.
- Investigating hotel types and market segments.
- Exploring monthly and seasonal booking trends.

**3. Customer & Market Analysis**
- Market segment analysis.
- Country-wise guest distribution.
- Customer and guest composition analysis.

**4. Revenue & Pricing Analysis**
- Average Daily Rate (ADR) analysis.
- Comparing ADR across market segments.
- Investigating pricing patterns across reserved room types.

**5. Cancellation Analysis**
- Comparing cancelled and non-cancelled bookings.
- Exploring factors associated with booking cancellations.

## 📈 Key Findings

- Online Travel Agents (Online TA) represent the largest market segment in the analysed dataset.
- Booking patterns vary across months and market segments.
- Room reservation and actual room allocation can differ.
- Cancellation analysis provides useful insights into booking behaviour and hotel operations.

## 🚀 Running the Streamlit Dashboard

**1. Clone the repository**

```bash
git clone https://github.com/kusum-kumar/Hotel-Booking-Data-Analysis.git
```

**2. Navigate to the project folder**

```bash
cd Hotel-Booking-Data-Analysis
```

**3. Install the required libraries**

```bash
pip install -r requirements.txt
```

**4. Place the cleaned dataset**

Place `hotel_bookings_cleaned.csv` in the same directory as `app.py`.

**5. Run the dashboard**

```bash
streamlit run app.py
```
